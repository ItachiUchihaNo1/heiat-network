# تنظیم ساده ارسال TSMS
در فایل خصوصی /home/ouidoyhy/_namira_live/config.local.json این بخش را به تنظیمات موجود اضافه کنید:
```json
"sms": {
  "enabled": true,
  "username": "نام کاربری واقعی پنل",
  "password": "رمز واقعی وب‌سرویس",
  "sender": "شماره خط ارسال"
}
```
این قطعه داخل شیء JSON فعلی قرار می‌گیرد؛ قبل از "sms" ویرگول بگذارید و آخرین } فایل را نگه دارید. تنظیمات دیتابیس حذف یا تکرار نشوند. بخش sms بر کلیدهای قدیمی SMS اولویت دارد؛ برای توقف ارسال enabled را false کنید.
فهرست شماره مجاز نداریم؛ هر کاربر برای شماره همراه خودش کد می‌گیرد. کد ۶رقمی، اعتبار دو دقیقه، فاصله ارسال مجدد یک دقیقه و سقف پنج درخواست هر شماره در ساعت از همه IPها است.
آدرس و GET داخل TsmsClient نگهداری می‌شوند: نسخه HTTPS همان مسیر /url/tsmshttp.php از نمونه Python با from,to,username,password,message. بررسی گواهی TLS همیشه فعال است؛ fallback به HTTP یا دنبال‌کردن redirect حاوی رمز نداریم. موفقیت اتصال با وجود تنظیمات تضمین نمی‌شود؛ پاسخ خالی، خطا و پاسخ ناشناخته موفق محسوب نمی‌شود. شناسه پذیرش با تحویل قطعی متفاوت است.
کلید امنیتی OTP خارج از هر دو docroot در _namira_live/.otp-secret نگهداری می‌شود و در استقرار، اگر وجود نداشته باشد، تصادفی ایجاد می‌شود. OTP_SECRET موجود اولویت دارد و تغییر نمی‌کند. لازم نیست این کلید را دستی اضافه کنید.
PHP cURL، mbstring و اجازه اتصال خروجی HTTPS هاست لازم‌اند.
اعلان آینده: (new SmsService($db))->notify($mobile,$message,'order:125:shipped:v1')
فعلاً پیامک سفارش/درخواست طراحی خودکار متصل نشده است. شناسه رویداد تکراری تا هفت روز دوباره ارسال نمی‌شود؛ پس از timeout تکرار خودکار انجام نمی‌شود.
آزمون: php tests/tsms.php
آزمون‌ها انتقال ساختگی دارند و هیچ پیامک واقعی بدون اجازه ارسال نمی‌شود.
