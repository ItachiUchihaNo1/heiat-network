# رابط قرمز و حساب — ارتقای 008
دامنه هدف فقط test.shahidpics.com، مسیر دقیق Public_html/new است.

## اصلاح 503
Web::run قالب request را بدون db فراخوانی می‌کرد؛ request.php متغیر تعریف‌نشده را به MemberSchema::ready(PDO) می‌داد.
این TypeError با اجرای مستقل بازتولید و در لاگ واقعی هاست (خواندن محدود و پالایش‌شده) تأیید شد.
اکنون db و user به قالب منتقل می‌شوند. مهمان به ورود هدایت می‌شود؛ عضو و مدیر دارای موبایل تأییدشده فرم واقعی را می‌بینند.
آزمون worker، خود Web::run، نشست و دیتابیس مستقل را برای مهمان303 و کاربر مجاز200 و مسیر پیش از ارتقا200 اجرا می‌کند.

## رابط
theme.css منبع مرکزی رنگ اصلی A82935، حالت تیره7F1D2D، زمینه ملایمFBEDEF، خنثی‌ها، focus و رنگ‌های معنایی است.
تصاویر، فایل‌های اصلی و داده عنوان‌های داخلی تغییر نمی‌کنند. لوگوی فعلی حرف CSS است؛ فقط رنگ آن عوض می‌شود و شکل دست‌نخورده است.
هدر بر اساس نشست سرور ورود/ثبت‌نام یا آواتار حرف اول نام دارد. آواتار از بانک هنرمند قرض گرفته نمی‌شود.
نمای عمومی شهید فقط بخش‌ها و ردیف‌های دارای مقدار معنادار را نشان می‌دهد؛ صفر فرزندان حفظ و placeholder نامشخص حذف می‌شود.
سن فقط با داده معتبر موجود محاسبه می‌شود. متن طولانی، واقعه و منابع عمومی معتبر حفظ می‌شوند؛ راهنمای مدیر و شناسه داخلی نمایش ندارد.
دکمه مشارکت کنار اقدام دانلود پرونده است. دانلود مجاز همچنان عمومی است؛ محدودیت مجوز با حذف متن توضیحی دور زده نمی‌شود.
عنوان فنی تصویر فقط در نمایش با نام معتبر موجود جایگزین می‌شود؛ دیتابیس و نام فایل اصلی دست‌نخورده است.
هنرمند: معرفی با آواتار کوچک دایره‌ای، داده عمومی موجود، کارت کوتاه و N اثر. شهرستان، فیلد JSON افزایشی است و خودکار عمومی نمی‌شود.

## ورود و ثبت‌نام تأییدشده
کاربر سیاست OTP اصلی + موبایل و رمز دائمی امن را تأیید کرده است. سقف شش‌کاراکتر یا PIN اعمال نشده است.
ورود عادی با موبایل تأییدشده و hash موجود users.password_hash، محدودیت نرخ IP/موبایل ۸ تلاش در۹۰۰ثانیه و پاسخ خطای یکسان.
رمز دائمی حداقل۱۲نویسه است؛ تنظیم یا بازیابی جدید فقط پس از proof معتبر OTP. رمز در داده بازگشت خطا ذخیره نمی‌شود.
مسیر ایمیل و رمز حساب‌های قدیمی/مدیران با legacy=1 حفظ است و شماره ساختگی به آن‌ها تحمیل نمی‌شود.
ثبت‌نام ابتدا فقط شماره همراه دارد؛ پس از OTP نام و نام خانوادگی ضروری و استان/شهرستان اختیاری دریافت می‌شوند.
شماره تکراری به همان شناسه پایدار می‌رسد. مکان حساب خصوصی است و به پروفایل عمومی هنرمند منتقل نمی‌شود.
سرویس پیامکی واقعی هنوز معرفی/متصل نشده است؛ ارسال کد و ثبت‌نام OTP فعلاً غیرفعال‌اند. هیچ اتصال واقعی شبیه‌سازی نمی‌شود.

## Migration
008_account_location فقط account_locations با FK به users و protocol_terms می‌سازد؛ credential و نقش‌ها تغییر نمی‌کنند.
مدیر اصلی یک بار پنل را باز کند تا SQL پشتیبان، گزارش شمارش و migration اجرا شود.
گزارش خصوصی: storage/backups/migration-008-*.json. در بازگشت کد، جدول مکمل حذف نشود.
استان و شهرستان از مرجع فعال می‌آیند؛ شهرستان باید فرزند استان باشد. مقدار خالی اختیاری است؛ حذف مقدار ارسال‌نشده با پاک‌کردن عمدی یکی نیست.
