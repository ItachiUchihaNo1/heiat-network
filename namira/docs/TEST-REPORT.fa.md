# گزارش آزمون نامیرا

تاریخ: ۲۰۲۶-۱۰-۲۳

۳۴ آزمون رفتاری روی SQLite و ۳۴ آزمون روی MySQL در GitHub Actions موفق شدند. بررسی syntax برای ۳۲ فایل PHP موفق است.

مرورگر محلی: فیلتر استان، عرض موبایل، افزودن کالا به سبد و خرید با درگاه صریحاً آزمایشی تا تأیید فاکتور بررسی شدند. دانلود اصل از HTTP با hash فایل ذخیره‌شده تطبیق داشت. stylesheet مرجع با نسخه استخراج‌شده تطابق متنی دارد؛ آزمون تصویری خودکار همه صفحات انجام نشده است.

اتصال TLS به cp173.mihanvps.com روی پورت ۲۱ با موفقیت تأیید شد. مقصد اعلام‌شده Public_html/new است. تلاش پیشین انتقال به علت خطای 530 ورود متوقف شد؛ کاربر اصلاح اطلاعات ورود را اعلام کرده و اجرای تازه لازم است. استقرار موفق هنوز تأیید نشده است.

محدودیت‌ها و بخش‌های تکمیل‌نشده در STATUS.fa.md ثبت شده‌اند؛ پرداخت بانکی واقعی فعال نیست.
