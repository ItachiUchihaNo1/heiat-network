# انتقال دستی سایت و پنل نامیرا

بسته دستی از همان آرشیو کد استفاده می‌کند که آزمون‌های گیت‌هاب برای آن موفق شده‌اند. یک هسته مشترک، هم سایت `naamiraa.ir` و هم پنل `admin.naamiraa.ir` را به‌روز می‌کند؛ فایل‌ها را جداگانه روی ورودی‌های سایت کپی نکنید.

ZIP را با SCP یا ابزار انتقال فایل به پوشه خانگی `naamiraadmin` روی VPS ببرید و در یک پوشه جدید خارج از ریشه وب استخراج کنید. سپس `sudo bash install.sh` را از پوشه استخراج‌شده اجرا کنید. برای بررسی بدون نصب می‌توان `bash install.sh --check` را اجرا کرد.

نصاب از ابزار root-owned نصب‌شده در `/usr/local/lib/namira-deploy` با حساب محدود `namira-deploy` استفاده می‌کند. ارتباط گیت‌هاب با SSH لازم نیست. این روش مخصوص VPS فعلی است که راه‌اندازی اولیه استقرار روی آن انجام شده است و برای نصب مستقیم در cPanel نیست.

Checksum بسته، مسیر فایل‌ها، PHP lint، افزونه‌ها و نسخه schema بررسی می‌شوند. پیش از تعویض نسخه، SQL و شمارش رکوردهای دیتابیس موجود `namira_app` در `/var/backups/naamiraa/deploy` ذخیره می‌شود. هر دو ورودی از نسخه جدید استفاده می‌کنند؛ شکست بررسی HTTPS باعث برگشت اشاره‌گر کد به نسخه قبل می‌شود.

هیچ config، رمز، کلید، دیتابیس اولیه یا فایل آپلودی داخل بسته نیست. فایل‌های `config.local.json`، storage، تنظیمات Nginx و ورودی‌های فعلی سایت و پنل جایگزین نمی‌شوند. این نصاب migration اجرا نمی‌کند؛ در صورت عقب‌بودن schema متوقف می‌شود. پشتیبان مستقل فایل‌ها و خارج از VPS همچنان لازم است.

نصب واقعی با دریافت خروجی موفقیت و بررسی نسخه سایت تأیید می‌شود. موفقیت آزمون‌های کد به معنی نصب روی VPS نیست.
