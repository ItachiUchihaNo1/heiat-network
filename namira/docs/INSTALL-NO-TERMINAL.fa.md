# نصب نامیرا بدون Terminal

این روش فقط نامیرا را در Public_html/new و یک دیتابیس کاملاً خالی و اختصاصی نصب می‌کند. به دیتابیس سایت اصلی وصل نشوید. دیتابیس دارای جدول توسط نصب‌کننده رد می‌شود.

۱. در cPanel → MySQL Database Wizard، یک دیتابیس با پسوند namira و یک کاربر MySQL بسازید. نام کامل هر دو همراه پیشوند حساب را یادداشت کنید. رمز را در جای امن خودتان نگه دارید. در مرحله آخر، همان کاربر را با ALL PRIVILEGES به همان دیتابیس متصل کنید.

۲. در cPanel → File Manager، از Settings گزینه Show Hidden Files را فعال کنید. وارد مسیر دقیق Public_html/new/_namira شوید. فایل .setup.key را با View باز کنید و کل رشته ۶۴ کاراکتری داخل آن را بردارید. این کلید را در چت، GitHub، تصویر عمومی یا آدرس URL قرار ندهید.

۳. نشانی زیر را باز کنید:
https://test.shahidpics.com/index.php?page=setup

۴. کلید را در کادر «کلید خصوصی نصب» وارد کنید. سپس مشخصات دیتابیس را وارد کنید: میزبان معمولاً localhost است، پورت معمولاً 3306 است؛ نام دیتابیس و کاربر کامل باشند. اگر میزبان شما مقدار متفاوتی ارائه می‌کند، همان مقدار را استفاده کنید.

۵. ایمیل مدیر و یک رمز جدید حداقل ۱۲ کاراکتری و تکرار آن را وارد کنید. روی «نصب روی دیتابیس خالی و ساخت مدیر» بزنید. رمزهای دیتابیس و مدیر را فقط داخل همین فرم HTTPS وارد کنید؛ نیازی به ارسال آنها برای دستیار نیست.

۶. پس از موفقیت به صفحه ورود هدایت می‌شوید. اطلاعات به‌صورت خصوصی در _namira/config.local.json ذخیره می‌شود، کلید نصب مصرف می‌شود و نصب‌کننده دیگر فعال نیست. فایل .env برای این روش لازم نیست. رمز مدیر فقط به‌صورت hash در MySQL ذخیره می‌شود. پرداخت واقعی غیرفعال می‌ماند.

۷. وارد مدیریت شوید، یک شهید واقعی یا رکورد آزمایشی مشخص ثبت کنید و یک تصویر مطابق کد، مثلاً 001254-1.jpg، بارگذاری کنید. در آرشیو عمومی همان فایل را بررسی کنید.

اگر خطای نام کاربری یا رمز MySQL دیدید، همان مشخصات کاربر اختصاصی دیتابیس را اصلاح کنید؛ این رمز FTP نیست. اگر خطای دسترسی دیدید، اتصال کاربر به دیتابیس و مجوزها را در cPanel بررسی کنید. هیچ جدول موجودی توسط نصب‌کننده بازنویسی نمی‌شود. اگر migration به‌علت محدودیت هاست نیمه‌کاره ماند، دیتابیس خالی جدید برای تلاش بعدی انتخاب کنید؛ به دیتابیس اصلی دست نزنید.

انتقال مجدد، config.local.json و storage و قفل نصب را نگه می‌دارد. کلید جدید فقط برای یک نصب تنظیم‌نشده ساخته می‌شود و مقدار آن در لاگ Actions چاپ نمی‌شود.
