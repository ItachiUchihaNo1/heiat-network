# فیلترهای تعاملی گالری نامیرا
نوار افقی لمسی با هفت دکمه به ترتیب موضوعی، نوع محدوده جغرافیایی، کشور، استان، شهرستان، شهر، سایر فیلترها جایگزین فرم اصلی شده است. رنگ سبز، فونت و کارت‌های نامیرا حفظ شده‌اند. مرجع تعامل: https://www.digikala.com/search/category-mobile-phone/ ؛ رنگ یا برند دیجی‌کالا وارد نشده است.

پنجره بومی dialog در موبایل از پایین و در دسکتاپ به صورت پنجره محدود زیر دکمه باز می‌شود. عنوان، بستن، جست‌وجو، فهرست اسکرول‌پذیر و ناحیه ثابت پاک‌کردن/نمایش تعداد واقعی دارد. dialog صفحه پشت را inert می‌کند؛ قفل اسکرول، بستن با Escape/پس‌زمینه و بازگرداندن فوکوس پیاده شده‌اند. اندازه لمس حداقل۴۴ پیکسل، reduced motion و تغییر ارتفاع صفحه‌کلید در نظر گرفته شده‌اند.

انتخاب‌ها تا اعمال موقت‌اند؛ بستن پنجره، داده فعال و URL را عوض نمی‌کند. پس از اعمال، AJAX نتایج، شمارش، برچسب‌ها و URL را به‌روز می‌کند؛ Back/Forward و صفحه‌بندی نیز پشتیبانی می‌شوند. خطای شبکه نتیجه قبلی را حفظ می‌کند و دکمه تلاش مجدد داخل پنجره دارد. پاسخ قدیمی درخواست هم‌زمان کنار گذاشته می‌شود. هیچ LocalStorage یا نسخه موقت مرورگری جایگزین دیتابیس نشده است.

گزینه‌ها از تصاویر طراحی‌شده قابل نمایش همین گالری و روابط عمومی media_public_martyrs به شهدای منتشرشده محاسبه می‌شوند. رکورد فرهنگ، پرونده منتشرشده بدون تصویر، تصویر پیش‌نویس و نوع رسانه خارج از گالری گزینه نمی‌سازند. گزینه‌های یک محور بدون محدودیت خود آن محور محاسبه می‌شوند تا انتخاب OR و تغییر انتخاب تکی ممکن بماند؛ سایر محورها AND هستند. والد سلسله‌مراتبی تنها وقتی ظاهر می‌شود که زیرمجموعه دارای تصویر داشته باشد. شمارش تصاویر distinct است و همه ویژگی‌ها باید روی یک شهید مرتبط با تصویر منطبق باشند.

محدوده جغرافیایی از نقش‌های واقعی دارای تصویر می‌آید. کشور/استان/شهرستان/شهر با نقش و والدهای انتخاب‌شده و همان fact جغرافیایی محدود می‌شوند. تغییر نقش یا والد، فقط انتخاب پایین‌دستی ناسازگار را حذف و با پیام گزارش می‌کند؛ مکان دیگری حدس یا انتخاب نمی‌شود. انتخاب نقش به‌تنهایی تصاویر دارای آن نوع مکان را محدود می‌کند. پیش از انتخاب نقش، کشورها براساس نقش پیش‌فرضِ دارای داده نشان داده می‌شوند و نام آن نقش در پنجره مشخص است؛ انتخاب مکان، همان نقش را صریحاً در URL ثبت می‌کند.

موضوعات collection و محورهای موضوعی تنظیم‌شده مستقیم در پنجره موضوعی نمایش داده می‌شوند؛ مرحله «مجموعه موضوعی» حذف است. سایر محورهای عمومی دارای گزینه و تاریخ در فهرست سایر قرار دارند و موضوعی/محدوده‌های اصلی تکرار نمی‌شوند. محور سفارشی با داده منتشرشده خودکار وارد می‌شود. محورهای جغرافیایی سفارشی که جزء چهار سطح واقعی مکان نیستند نیز به صورت محور تخصصی در سایر قابل دسترسی‌اند. داده و تنظیمات مرکزی دسته‌بندی تغییر معنا نکرده‌اند.

مسیر فقط‌خواندنی GET: index.php?page=gallery-data&mode=preview یا mode=results، با همان پارامترهای محور، جغرافیا و تاریخ گالری. changed فقط برای کلید نقش/والد جغرافیا مجاز است. خطاها JSON با وضعیت HTTP صحیح هستند. mode=results، HTML امن سمت سرور و URL بازگشت را هم برمی‌گرداند. کوئری‌ها پارامتری‌اند؛ داده خصوصی، اتصال فایل اصلی و ساختار دیتابیس تغییر نکرده‌اند. نمونه بدون جاوااسکریپت در noscript حفظ شده است.

آزمون: php tests/gallery-facets.php و node tests/gallery-filter-state.cjs ؛ CI همین آزمون دیتابیس را روی MySQL مستقل namira_test_facets اجرا می‌کند. این آزمون‌ها جای بررسی واقعی ظاهر، لمس و فوکوس روی دستگاه را نمی‌گیرند. فقط test.shahidpics.com / Public_html/new مقصد استقرار است.
