# ویترین و مدیریت صفحه اصلی نامیرا

مسیر مدیریت: پنل مدیریت ← مدیریت صفحه اصلی (مجوز settings.manage).
هفت نوع بلوک قابل تکرار: بنر، تصاویر، درخواست طراحی، محصول، فراخوان، هنرمند و شهید.
مرتب‌سازی با دکمه بالا/پایین انجام می‌شود؛ نیازی به کشیدن یا دانش فنی نیست.
هر بلوک عنوان، وضعیت نمایش و فقط تنظیمات مرتبط خود را دارد.
انتخاب دستی از جست‌وجوی محتوای منتشرشده و چک‌باکس انجام می‌شود.

«ذخیره پیش‌نویس» صفحه عمومی را تغییر نمی‌دهد. پیش‌نمایش موبایل/دسکتاپ از پیش‌نویس ذخیره‌شده خوانده می‌شود؛ اگر تغییر ذخیره‌نشده وجود داشته باشد، ابتدا پیش‌نویس ذخیره می‌شود.
«ذخیره و انتشار» چیدمان را مستقیم منتشر می‌کند. خروج با تغییرات ذخیره‌نشده هشدار دارد.
ویرایش هم‌زمان با version کنترل می‌شود؛ خطای ذخیره یا تعارض، ورودی مرورگر را حفظ می‌کند.

## داده و امنیت
از جدول موجود app_settings، کلید home_showcase_v1 استفاده می‌شود؛ جدول یا ستون جدیدی ساخته نمی‌شود.
کلید شامل draft/published/version/published_at است. نبود کلید، چیدمان اولیه هفت‌بخشی را نمایش می‌دهد.
انتشار، پشتیبان JSON خصوصی چیدمان قبلی را در storage/backups/home-layout-*.json می‌سازد و audit ثبت می‌کند.
حذف بلوک هیچ شهید، تصویر، محصول، هنرمند یا فراخوانی را حذف نمی‌کند.
تصاویر از Archive، هنرمندان از snapshot عمومی، محصولات از StoreCatalog و فراخوان‌ها از وضعیت و بازه مجاز موجود خوانده می‌شوند.
محتوای دستیِ خارج از نمایش، بدون افشای داده کنار گذاشته می‌شود؛ شناسه تنظیمات محفوظ می‌ماند.
فراخوان فقط هنگام published، accepting و در بازه دریافت آثار نمایش داده می‌شود.
بنر JPEG/PNG/WebP اعتبارسنجی و به WebP بهینه تبدیل می‌شود؛ فایل‌ها خصوصی هستند و فقط بنرهای چیدمان منتشرشده قابل دریافت عمومی‌اند.
برای موبایل و دسکتاپ فایل جدا می‌توان انتخاب کرد. فایل‌های پیش‌نویس، مسیرهای محافظت‌شده مدیریتی دارند.
محدودیت حفاظتی: ۲۰ بخش، حداکثر ۲۴ آیتم در هر بخش و حداکثر ۶۰ کیلوبایت تنظیمات کامل.
فایل‌های بنر قدیمی هنگام حذف/جایگزینی خودکار پاک نمی‌شوند تا نسخه منتشرشده و بازگشت چیدمان آسیب نبیند؛ پاک‌سازی دوره‌ای فایل‌های بدون ارجاع باید جداگانه و با پشتیبان انجام شود.

## اجرا و آزمون
همان راه‌اندازی PHP/MySQL پروژه استفاده می‌شود؛ هیچ سرویس خارجی یا بسته جدید برنامه لازم نیست.
php tests/home-showcase.php
برای MySQL فقط دیتابیس ایزوله namira_test_showcase با متغیر TEST_SHOWCASE_DB_DSN و TEST_DB_USER/TEST_DB_PASSWORD استفاده شود.
node tests/home-showcase-ui.cjs
آزمون مرورگر به Playwright/Chromium در محیط توسعه/CI نیاز دارد؛ هیچ ابزار مرورگر یا مسیر تستی در public استقرار داده نمی‌شود.

بازگشت برنامه با pointer نسخه قبلی انجام می‌شود؛ داده‌های محتوا تغییر نمی‌کنند. کلید ویترین در app_settings می‌ماند و نسخه‌های قبلی آن را نادیده می‌گیرند.
