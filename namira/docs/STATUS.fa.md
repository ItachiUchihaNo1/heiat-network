# وضعیت تحویل و محدودیت‌ها

## پیاده‌سازی‌شده و قابل آزمون

- ساختار مستقل PHP و PDO؛ migration قابل اجرای مجدد؛ MySQL برای هاست و SQLite برای توسعه.
- قالب مشترک RTL، Masonry با CSS مرجع v2، خانه، آرشیو، پروفایل، جزئیات تصویر، فرم درخواست، فروشگاه و پنل.
- ثبت و ویرایش شهید با کد متنی یکتا، فیلدهای حداقلی و اختیاری، دسته چندانتخابی و انتشار.
- اصل تصویر بدون تغییر بایت، preview و thumbnail WebP، بارگذاری چندفایلی با تطبیق کد، بررسی MIME/ابعاد/حجم و رد payload آشکار PHP؛ دریافت بدون ورود.
- فیلتر ترکیبی استان، شهر، شغل، سازمان، موضوع، نام/کد، جهت و مرتب‌سازی؛ فیلتر kind/mime در سرویس فراهم است ولی انتخابگر UI آن هنوز اضافه نشده است.
- XLSX واقعی دوشیت از نتیجه فیلتر شهدا؛ کد متنی و ضد تفسیر فرمول. ورود اولیه با پیش‌نمایش، گزارش خطا و حفظ رکوردهای موجود.
- درخواست رایگان با تصاویر اولیه خصوصی، رضایت، کد تصادفی و مدیریت وضعیت ساده.
- محصول و تنوع در دیتابیس، فیلتر ساده، سبد پایدار سمت سرور، snapshot سفارش، تخفیف درصدی پایه در سرویس و موجودی تراکنشی.
- پرداخت صرفاً آزمایشی؛ در production غیرفعال؛ callback تکراری، خطا و آزادسازی موجودی آزمون شده است.
- فاکتور قابل چاپ، رهگیری دستی، وضعیت سفارش و ثبت درخواست مرجوعی.
- نقش‌های مدیریت اصلی، محتوا و فروشگاه، CSRF، escape خروجی، query پارامتری، محدودسازی نرخ، لاگ عملیات و cookieهای نشست.
- استقرار FTPS با گواهی معتبر، مقصد پیش‌فرض Public_html/new، کنترل HTTP403 پوشه خصوصی و حفظ .env/storage.

## هنوز تکمیل نشده

- هیچ محتوای واقعی شهدا، تصویر اصلی واقعی، محصول قابل فروش یا اطلاعات مجوز آثار در سه مرجع وجود نداشت؛ باید توسط بهره‌بردار وارد شود. seed با برچسب آزمایشی فقط برای توسعه است.
- صف حجیم، chunk processing، نوار پیشرفت بارگذاری، retry خودکار موارد ناموفق و resume job پایدار؛ ورودی فعلی محدود و هم‌زمان است.
- انتخاب تصویر شاخص مستقل و مرتب‌سازی دستی گالری؛ فعلاً اولین شماره تصویر به‌عنوان تصویر شاخص نمایش داده می‌شود.
- صوت، ویدئو، اسناد غیرتصویری، ثبت منابع مجزا، جغرافیای تفکیک‌شده تولد/شهادت/دفن و تاریخ‌های قابل جست‌وجوی ساختاریافته؛ بخشی از داده فعلاً متن اختیاری است.
- پیشنهاد خودکار شهید موجود داخل فرم درخواست، ارسال تکمیل اطلاعات توسط مخاطب و صف تأیید محتوای عمومی.
- حساب عضو و OTP، آدرس‌های حساب، جست‌وجوی پیشرفته متن فارسی، URLهای پاک، sitemap و متادیتای کامل اشتراک‌گذاری.
- ویرایش کامل محصول/تنوع از پنل، گالری محصول مستقل، ثبت گردش موجودی و هشدار کمبود، تولید بر اساس سفارش، مدیریت تخفیف پیشرفته، گزارش فروش/ارسال و خروجی سفارش‌ها.
- افزودن تنوع بعدی و کد تخفیف از UI؛ ساختار داده پشتیبانی می‌کند ولی UI مدیریتی هنوز کامل نیست.
- پرداخت بانکی واقعی، تلاش مجدد واقعی پرداخت، تسویه و استرداد واقعی؛ callback واقعی بانک وجود ندارد.
- API ارسال، نرخ لحظه‌ای پست، ثبت و چاپ لیبل، پیامک سفارش، پنل رسیدگی کامل مرجوعی و استرداد.
- مجوزهای ریزدانه پویا؛ نقش‌ها فعلاً سه نقش ثابت مدیریت هستند. ویرایش کاربران از CLI انجام می‌شود.
- پنل پشتیبان‌گیری، پشتیبان‌گیری خارج سرور، تست بازیابی خودکار، rollback کامل migration و atomic release چندفایلی.
- صفحات حقوقی کامل، اطلاعات تماس رسمی، تست دسترس‌پذیری/مرورگرهای گسترده، بار ۴۰۰۰ شهید و آزمون LCP/INP/CLS.

## وضعیت آزمون و استقرار

آزمون محلی اولیه: ۳۳ بررسی رفتاری روی PHP 8.4.27 و SQLite موفق بود؛ همچنین تمام فایل‌های PHP موجود در آن لحظه syntax check شدند. خانه و آرشیو در مرورگر باز شدند و فیلتر استان تهران نتیجه را از ۹ به ۳ تصویر تغییر داد. CSS مرجع استخراج شده است؛ مقایسه تصویری خودکار همه صفحات انجام نشده است. هیچ تأیید عملکرد نهایی یا بهره‌برداری از این تست محدود نتیجه گرفته نمی‌شود.

وضعیت نهایی MySQL در GitHub Actions و انتقال روی هاست باید از اجرای واقعی workflow خوانده شود. تنظیم‌نبودن secrets، ریشه FTP، TLS، MySQL یا migration مانع تأیید استقرار است. فایل منتقل‌شده با سایت آماده بهره‌برداری یکسان نیست.

## افزایش نصب بدون Terminal

نصب‌کننده مرورگری محافظت‌شده با کلید خصوصی، CSRF، محدودیت تلاش، قفل نصب هم‌زمان و مصرف یک‌باره کلید اضافه شد. دیتابیس غیرخالی رد می‌شود؛ مشخصات خصوصی در config.local.json و رمز مدیر به صورت hash ذخیره می‌شوند. ۱۸ تست نصب‌کننده روی SQLite محلی موفق شدند؛ آزمون MySQL و انتقال باید در اجرای جدید تأیید شوند. این افزایش سایر امکانات ناتمام بالا را تکمیل نمی‌کند.
