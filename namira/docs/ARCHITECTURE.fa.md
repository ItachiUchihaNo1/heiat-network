## تصمیم معماری

هاست اعلام‌شده cPanel و زبان درخواستی PHP است. این افزایش مستقل زیر namira/ به مخزن موجود Next.js اضافه می‌شود؛ کد قبلی heiat-network بازنویسی نمی‌شود. PHP 8.4، PDO، MySQL/InnoDB و رندر HTML سمت سرور استفاده شده است. این یک modular monolith با کنترلر ورودی، سرویس‌های مستقل Archive، Upload، Importer، Xlsx، DesignRequests و Shop و templateهای مشترک است. کاربرد framework در افزایش بعدی باید همراه با migration تدریجی باشد؛ تغییر ظاهر برای آن لازم نیست. اجرای PHP بدون سرویس Node و بدون daemon دائمی روی cPanel ممکن است. نسخه اولیه پردازش بزرگ پس‌زمینه ندارد و این محدودیت صریح است.

پول به‌صورت عدد صحیح تومان ذخیره می‌شود. تبدیل به ریال باید در adapter درگاه واقعی صریحاً آزمون شود. کد آرشیو varchar است و شناسه داخلی مستقل دارد. حذف رکوردها از UI فراهم نیست تا روابط آرشیو و سفارش با حذف ساده از بین نرود؛ توقف انتشار فراهم است. فایل اصلی از فایل پیش‌نمایش جداست و بر پایه hash تشخیص تکرار دارد.

خرید با snapshot عنوان، تنوع، قیمت و تعداد انجام می‌شود. موجودی با UPDATE شرطی در تراکنش رزرو می‌شود. checkout_key مانع ثبت دوباره سفارش از یک تسویه است. callback آزمایشی و تغییر وضعیت سفارش با قفل ردیف MySQL و تراکنش انجام می‌شود؛ callback تکراری دوباره موجودی را برنمی‌گرداند. کار انقضای سفارش برای آزادسازی رزرو لازم است.

## اتصال‌های خارجی

PaymentGateway قرارداد اتصال است. TestGateway فقط برای APP_ENV غیر production و PAYMENT_DRIVER=test مجاز است. هیچ adapter واقعی برای بانک، پست یا پیامک نوشته یا آماده بهره‌برداری اعلام نشده است. هزینه ارسال فعلاً تنظیم ثابت و رهگیری دستی است. افزوده‌شدن adapter واقعی باید شامل درخواست تراکنش، verify سمت سرور، بررسی مبلغ/ریال، شناسه یکتا، خطا، retry، ثبت وضعیت و reconciliation باشد. OTP تا اتصال پیامک و تست نرخ و انقضا فعال نمی‌شود.

## نقشه مراحل و خروجی قابل آزمون

1. معماری و تبدیل رابط: ساختار app/views/public، CSS مرجع، هدر مشترک، آرشیو و پروفایل؛ اجرا با php -S و مرور خانه/آرشیو/پروفایل.
2. بانک و مدیریت فایل: migration، شهدا و دسته‌ها، دریافت اصل، preview، فیلتر، ورود/خروج XLSX و نقش‌ها؛ تست tests/run.php و فرم مدیریت.
3. درخواست رایگان و هسته فروشگاه: درخواست پایدار، کد پیگیری، محصول/تنوع، سبد دیتابیسی، checkout آزمایشی و چرخه سفارش؛ تست موفق/ناموفق و موجودی.
4. اتصال واقعی سرویس‌ها و تکمیل مدیریت: پرداخت، پیامک OTP، پست، تخفیف‌های کامل، گزارش، محتوای چندرسانه‌ای و صف؛ نیازمند توسعه بعدی و اطلاعات ارائه‌دهندگان.
5. پذیرش بهره‌برداری: MySQL هاست، بازیابی واقعی، داده آرشیو، مجوز آثار، سیاست فروش، تست موبایل گسترده، کارایی و مانیتورینگ. تا اجرای این پذیرش، این نسخه آماده افتتاح عمومی فروشگاه نیست.
